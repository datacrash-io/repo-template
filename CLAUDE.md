## Rules

- **No secrets in git.** Keys, tokens and `.env` files stay out of the repository and out of commit messages, logs and
  documentation. Name where a secret lives, never its value.
- **Changes come with their docs.** A change that alters documented behaviour updates the docs in the same pull request.
- **Pull requests are ready for review** unless a person asks for a draft.
- **Tests run before merge.** Every change that touches code has a test or says in the pull request why it has none.
